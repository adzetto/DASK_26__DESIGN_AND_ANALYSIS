## 📋 Project Overview

This repository contains the structural design and analysis for the **DASK 2026 Depreme Dayanıklı Bina Tasarımı Yarışması** (Earthquake-Resistant Building Design Competition).

The project features **twin towers** connected by bridges, utilizing an innovative **outrigger bracing system** for optimal lateral load resistance.
